# 淘宝商品上架校验清单

发布商品前逐项核对，确保无遗漏。

## 一、基础信息

- [ ] 商品标题已填写（25-30字，含核心关键词，无违禁词）
- [ ] 商品类目已选择正确（精确到最末级）
- [ ] 所有带 * 号的必填属性已填写
- [ ] 非必填属性尽量填写完整
- [ ] 品牌属性正确（无品牌选 other/其他）

## 二、图片素材

- [ ] 主图至少1张（建议5张全满）
- [ ] 主图尺寸 800x800px 以上，正方形
- [ ] 主图格式 JPG/PNG，单张不超过 3MB
- [ ] 首张主图无牛皮癣（文字占比不超过20%）
- [ ] 详情页图片已上传（宽度750px）
- [ ] 详情页包含：卖点、参数、细节、场景、售后
- [ ] SKU规格图已上传（如有多规格）
- [ ] 主图视频已上传（可选，9-30秒）

## 三、价格与库存

- [ ] 一口价已设置（不低于SKU最高价）
- [ ] 各SKU价格已设置（价差合理）
- [ ] 总库存或各SKU库存已设置
- [ ] 商家编码已填写（如有内部货号）

## 四、物流设置

- [ ] 运费模板已选择（或新建完成）
- [ ] 发货地址正确
- [ ] 发货时间承诺符合实际能力
- [ ] 偏远地区运费已设置

## 五、售后服务

- [ ] 发票设置已确认
- [ ] 保修设置已确认
- [ ] 7天无理由退换货已确认
- [ ] 运费险已开通（建议）

## 六、发布前最终检查

- [ ] 页面无红色错误提示
- [ ] 发布按钮可点击
- [ ] 选择「立即上架」而非「放入仓库」
- [ ] 已预览商品详情页效果

## 七、发布后核验

- [ ] 商品状态为「出售中」
- [ ] 商品详情页可正常打开
- [ ] 标题、主图、价格显示正确
- [ ] SKU选择正常，价格对应正确
- [ ] 详情页图片完整加载
- [ ] 「出售中的宝贝」列表中可搜到该商品
