# 淘宝商品标题优化指南

## 一、标题基本规则

- **长度**：最多30个汉字（60个字符），建议写满25-30字
- **字符**：一个汉字=2字符，一个英文/数字=1字符
- **符号**：可使用空格分隔关键词，避免特殊符号
- **唯一性**：同店铺商品标题不可完全重复

## 二、标题结构公式

```
核心词 + 属性词 + 营销词 + 长尾词/场景词
```

### 各部分说明

| 类型 | 说明 | 示例（中性笔） |
|------|------|----------------|
| 核心词 | 商品最本质的名称，搜索量最大 | 中性笔、签字笔 |
| 属性词 | 商品特征描述 | 0.5mm、黑色、按动式、速干 |
| 营销词 | 促销/卖点描述 | 学生用、办公、考试专用、大容量 |
| 长尾词 | 更精准的搜索组合 | 黑色中性笔0.5按动式学生用 |

### 示例标题
- 中性笔0.5mm黑色按动式速干学生考试用办公签字笔水笔
- 纯棉短袖T恤男2024夏季新款宽松圆领休闲半袖上衣

## 三、关键词策略

### 3.1 关键词来源
1. **淘宝搜索下拉框**：输入核心词，查看推荐搜索词
2. **生意参谋**：市场行情 → 搜索词查询（需付费）
3. **竞品标题**：分析同类目TOP商品标题关键词
4. **直通车流量解析**：查看关键词搜索指数
5. **淘宝排行榜**：查看行业热门搜索词

### 3.2 关键词选择原则
- **相关性**：关键词必须与商品实际匹配
- **搜索量**：优先选择有一定搜索量的词
- **竞争度**：新店铺/新商品优先选择长尾词（竞争小）
- **转化词**：包含「购买意向」的词（如「学生用」「办公」）

### 3.3 关键词排列
- 重要关键词放标题前半部分（权重略高）
- 核心词出现1次即可，不要重复堆砌
- 同义词可都放（如「中性笔」和「签字笔」）
- 用空格分隔不同关键词组，便于系统识别

## 四、违禁词清单（绝对不能用）

### 极限词（广告法禁用）
最、最佳、最好、最大、最高、最低、最便宜、第一、唯一、首个、首选、独家、全网第一、顶级、顶尖、绝对、永久、万能、100%、国家级、世界级、驰名商标

### 虚假宣传词
纯天然、零添加、无副作用、根治、药到病除、特效、强效（非药品类目）、减肥、瘦身（非保健食品类目）

### 敏感词
高仿、精仿、A货、原单、尾单、走私、水货、盗版

## 五、标题优化节奏

1. **新品期**：核心词 + 长尾词为主，避开大词竞争
2. **成长期**：根据搜索流量数据，替换无展现词
3. **稳定期**：保留高转化词，微调低点击词
4. **大促前**：加入大促相关词（如「618」「双11」「年货节」）

## 六、标题自检清单

- [ ] 字数在25-30字之间
- [ ] 包含1-2个核心搜索词
- [ ] 包含3-5个属性描述词
- [ ] 无极限词/违禁词
- [ ] 无关键词重复堆砌
- [ ] 读起来通顺，不是单纯关键词堆砌
- [ ] 与商品实际属性一致
- [ ] 同店铺无重复标题
