# 淘宝商品图片规范

## 一、主图规范

### 基本要求
- **尺寸**：建议 800x800px 及以上（正方形），支持放大镜功能
- **格式**：JPG、JPEG、PNG
- **大小**：单张不超过 3MB
- **数量**：至少1张，最多5张（部分类目支持更多）
- **背景**：建议白底或简洁背景，突出商品主体

### 首张主图（最重要）
- 商品主体占画面 70% 以上
- 文字/水印占比不超过 20%（避免牛皮癣）
- 无拼接、无边框、无多余装饰
- 清晰展示商品全貌
- 部分类目要求纯白背景（如服饰、数码）

### 后续主图建议
- 第2张：商品细节/材质特写
- 第3张：使用场景图
- 第4张：规格/尺寸说明图
- 第5张：包装/配件展示图

### 主图视频（可选）
- **时长**：9-30秒
- **尺寸**：建议 1:1 或 3:4
- **大小**：不超过 100MB
- **格式**：MP4
- 内容：商品动态展示、使用演示、细节特写

## 二、详情页图片规范

- **宽度**：统一 750px（淘宝详情页标准宽度）
- **高度**：不限，建议单张不超过 1500px
- **格式**：JPG、JPEG、PNG
- **大小**：单张不超过 3MB
- **分辨率**：72dpi 即可，无需300dpi（减小加载时间）

### 详情页结构建议
1. **首屏海报**（750x~1000px）：核心卖点 + 商品大图
2. **产品参数表**：规格、材质、尺寸等关键信息
3. **细节展示**：多角度特写，标注材质/工艺
4. **使用场景**：真人/实景展示使用效果
5. **颜色/规格展示**：各SKU对应图片
6. **品牌/售后说明**：品牌介绍、保修、退换货政策

## 三、SKU规格图

- **尺寸**：建议 400x400px 或 800x800px
- **格式**：JPG、PNG
- 每个规格值对应一张清晰图片
- 图片需准确反映该规格特征（如颜色、款式）

## 四、图片处理工具建议

- 批量调整尺寸：可使用 Python PIL/Pillow 脚本
- 压缩图片：TinyPNG 在线工具或本地压缩
- 抠图/换背景：移除背景工具
- 加水印：批量水印工具

## 五、常见图片违规

| 违规类型 | 说明 | 后果 |
|----------|------|------|
| 牛皮癣 | 主图文字过多、拼接、边框 | 搜索降权、强制下架 |
| 盗图 | 使用他人图片未经授权 | 投诉扣分、删除商品 |
| 夸大宣传 | 图片含虚假功效/极限词 | 违规扣分 |
| 图片与实物不符 | 图片展示与实际商品差异大 | 退款纠纷、投诉 |
| 含联系方式 | 图片中出现微信/QQ/电话 | 违规处罚 |
