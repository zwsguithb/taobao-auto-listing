# 淘宝常见类目与属性填写指南

## 一、类目选择原则

1. **精确优先**：选择最末级类目，不要停留在上级类目
2. **搜索验证**：在类目搜索框输入商品名称，选择匹配度最高的结果
3. **参考竞品**：查看同类热销商品的类目归属
4. **资质确认**：部分类目需要特殊资质，提前确认店铺是否具备

## 二、常见类目路径

### 文具/办公类
- 文具电教/文化用品/商务用品 → 笔类 → 中性笔
- 文具电教/文化用品/商务用品 → 笔类 → 圆珠笔/原子笔
- 文具电教/文化用品/商务用品 → 笔类 → 钢笔
- 文具电教/文化用品/商务用品 → 笔类 → 铅笔
- 文具电教/文化用品/商务用品 → 笔记本/记事本 → 笔记本/记事本

### 服饰类
- 女装/女士精品 → T恤
- 女装/女士精品 → 连衣裙
- 男装 → T恤
- 男装 → 衬衫

### 数码类
- 3C数码配件 → 手机配件 → 手机保护套/壳
- 3C数码配件 → 手机配件 → 手机数据线

### 食品类（需食品经营许可证）
- 零食/坚果/特产 → 饼干/膨化 → 饼干
- 咖啡/麦片/冲饮 → 速溶咖啡/咖啡豆/粉

## 三、类目属性填写要点

### 通用必填属性（多数类目）
| 属性 | 填写说明 |
|------|----------|
| 品牌 | 有品牌填品牌名，无品牌选「other/其他」 |
| 材质 | 如实填写商品主要材质 |
| 产地 | 商品生产地 |
| 颜色分类 | 如有多色，在此设置SKU颜色 |
| 规格 | 商品规格参数 |

### 文具类（笔类）常见属性
| 属性 | 示例值 |
|------|--------|
| 品牌 | 晨光、得力、真彩、other/其他 |
| 笔芯颜色 | 黑色、蓝色、红色、墨蓝 |
| 笔尖粗细 | 0.38mm、0.5mm、0.7mm、1.0mm |
| 笔的类型 | 按动式、插拔式 |
| 包装方式 | 单支、盒装（12支）、桶装 |
| 适用场景 | 学生用、办公用、考试用 |
| 是否可擦 | 是、否 |

### 服饰类常见属性
| 属性 | 示例值 |
|------|--------|
| 品牌 | 自有品牌名或 other/其他 |
| 面料 | 纯棉、涤纶、棉混纺 |
| 风格 | 简约、休闲、运动、商务 |
| 款式 | 圆领、V领、POLO领 |
| 袖长 | 短袖、长袖、无袖 |
| 厚薄 | 常规、薄款、加厚 |
| 适合季节 | 夏季、春秋、冬季 |

## 四、属性填写注意事项

1. **必填项必须填**：带红色 * 号的属性不填无法发布
2. **属性与标题一致**：属性值要与标题描述对应（如标题写0.5mm，属性笔尖粗细也选0.5mm）
3. **属性影响搜索**：填写完整的属性有助于搜索匹配和筛选展示
4. **不要乱填属性**：属性与实物不符会导致退款纠纷和投诉
5. **品牌属性谨慎**：非品牌商品不要乱填品牌名，避免侵权

## 五、需要资质的类目

| 类目 | 所需资质 |
|------|----------|
| 食品/饮料 | 食品经营许可证 |
| 化妆品 | 化妆品备案凭证 |
| 医疗器械 | 医疗器械经营许可证 |
| 图书/音像 | 出版物经营许可证 |
| 宠物药品 | 兽药经营许可证 |
| 酒类 | 食品经营许可证（含酒类） |

> 上架前确认店铺已完成对应类目资质备案，否则无法发布或发布后被下架。
