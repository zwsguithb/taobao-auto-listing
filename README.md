# 淘宝商品自动化上架 Skill (taobao-auto-listing)

> 淘宝/天猫店铺商品全流程自动化上架助手。扫码登录千牛后，从类目选择到发布核验全自动完成。

## ✨ 功能特性

- **🤖 全自动执行模式** — 扫码登录后，类目选择、信息填写、图片上传、SKU设置、物流售后、发布核验，全程自动连续完成，无需中途干预
- **📋 完整上架流程** — 覆盖资料准备 → 登录导航 → 类目选择 → 基本信息 → 图片上传 → SKU价格库存 → 物流售后 → 发布核验 全链路
- **🔄 异常自动恢复** — 页面加载慢、元素找不到、弹窗广告、图片上传失败等异常自动重试处理，仅验证码/登录失效等必须人工的场景才暂停
- **📊 上架结果汇总** — 完成后统一输出结构化结果（单个商品/批量/失败三种模板）
- **✅ 资料校验脚本** — Python 脚本自动检查商品资料 CSV 的必填项完整性和图片文件存在性
- **📚 配套参考文档** — 上架校验清单、图片规范、标题优化指南、类目属性填写指南

## 🚀 快速开始

### 安装

将本仓库克隆或复制到你的 Skill 目录：

```bash
git clone https://github.com/zwsguithb/taobao-auto-listing.git
```

放入 `.user_skills/` 目录下即可被 AI Agent 识别和调用。

### 使用步骤

1. **准备商品资料**
   - 复制 `assets/product-info-template.csv`，填写商品信息
   - 或直接用文字描述商品，由 AI 整理

2. **校验资料（可选）**
   ```bash
   python3 scripts/validate_product_info.py 你的商品资料.csv
   ```

3. **执行上架**
   - 对 AI 说：「帮我上架这个商品」并提供商品资料
   - 扫码登录千牛工作台
   - 等待全自动上架完成，查看结果汇总

## 📝 商品资料模板说明

| 字段 | 必填 | 说明 |
|------|------|------|
| 商品标题 | 是 | 25-30字，含核心关键词 |
| 商品类目 | 是 | 精确到末级类目路径 |
| 品牌 | 否 | 无品牌填 other/其他 |
| 核心属性 | 否 | 品牌、材质、规格等 |
| 主图路径1-5 | 是 | 本地图片绝对路径，800x800px以上 |
| 详情图路径 | 是 | 详情页图片目录路径 |
| SKU规格名称 | 视类目 | 如「颜色分类」「尺码」 |
| SKU规格值 | 视类目 | 如「黑色0.5mm」 |
| SKU价格 | 视类目 | 对应规格价格 |
| SKU库存 | 视类目 | 对应规格库存 |
| 一口价 | 是 | 商品统一价格或SKU最高价 |
| 总库存 | 是 | 商品总库存数量 |
| 商家编码 | 否 | 内部货号 |
| 运费模板 | 是 | 已创建的运费模板名称 |
| 发货时间 | 是 | 如「48小时内」 |
| 发票 | 是 | 是否提供发票 |
| 保修 | 是 | 保修期限 |

## 🔧 全自动执行模式说明

登录后自动执行以下阶段，中途不暂停：

| 阶段 | 操作 |
|------|------|
| 类目选择 | 搜索关键词，选择最匹配类目 |
| 基本信息 | 填写标题、属性、上传主图和详情图 |
| SKU设置 | 设置规格、价格、库存、商家编码 |
| 物流售后 | 选择运费模板、发货时间、发票保修 |
| 发布上架 | 点击发布，处理校验错误 |
| 上架核验 | 检查商品状态、详情页、SKU显示 |

**仅以下情况暂停通知用户：**
- 登录失效 / 验证码滑块
- 类目需要资质但店铺未具备
- 资料必填项缺失
- 连续3次操作失败

## ⚠️ 注意事项

1. **登录安全** — 扫码登录为必须步骤，无法自动化（淘宝安全机制）
2. **页面适配** — 淘宝卖家中心可能改版，如遇元素找不到会自动重试，仍失败则暂停
3. **类目资质** — 食品、化妆品、医疗器械等类目需提前完成资质备案
4. **图片合规** — 主图避免牛皮癣（文字占比超20%），详情图宽度统一750px
5. **标题合规** — 禁止使用极限词（最、第一、国家级等），避免违规下架
